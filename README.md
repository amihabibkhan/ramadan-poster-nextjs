# রমাদান কাউন্টডাউন পোস্টার মেকার (Ramadan Countdown Poster Maker)

সবার জন্য ফ্রি ক্লায়েন্ট-সাইড Next.js ওয়েব অ্যাপ্লিকেশন—যা দিয়ে ১-ক্লিকে ১০৮০×১০৮০ রেজোলিউশনের সিঙ্গেল পোস্টার কিংবা পুরো মাসের (যেমন ৩০ দিন থেকে ১ দিন পর্যন্ত) সব পোস্টার একসাথে ZIP আকারে ডাউনলোড করা যায়।

1. এই প্রজেক্ট ফোল্ডারটি আপনার GitHub রিপোজিটরিতে আপলোড করুন।
